## Claim
One LLM can draft, critique and revise its own output in a loop and beat single-pass generation on many tasks, with no training.
## Mechanism
- Generate an initial output.
- The same model writes actionable feedback on it.
- The same model rewrites the output using that feedback.
- Repeat until a stop condition or a fixed iteration count.
## Evidence
- Across 7 tasks with GPT-3.5 and GPT-4, reported gains over direct generation are 5-40% absolute.
- Code Optimization with GPT-4: 27.3 to 36.0 (+8.7).
- Dialogue Response Generation with GPT-4, preference score: 25.4% to 74.6%.
- Ablation: generic feedback instead of specific feedback drops Sentiment Transfer from 43.2 to 31.2.
## Limits
- Of failed cases analysed, 61% came from feedback proposing an inappropriate fix and 33% from feedback missing the error's location.
- Strongest gains are on preference-style tasks, where the same model also judges quality.
- Tested mainly on strong proprietary models; weaker models gain less.
## We adopt
Skills may use a draft-critique-revise pass to polish deliverables (copy, replies), but self-feedback is never evidence for promotion: it cannot move anything into memory (DESIGN.md#external-feedback-gate).
## We reject
Treating the loop's own critique as a quality signal for memory or skill changes, and open-ended iteration; the paper's failure analysis shows the critic is the weak link.
