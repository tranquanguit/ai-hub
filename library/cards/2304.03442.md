## Claim
A memory stream with scored retrieval, periodic reflection and planning lets LLM agents act believably over time.
## Mechanism
- Every experience is a natural-language memory with timestamps.
- Retrieval score is a sum of recency, importance and relevance, each min-max normalized to [0,1].
- Recency is exponential decay (factor 0.995 per game hour); importance is an LLM-rated integer assigned at creation; relevance is embedding similarity.
- Reflections are higher-level syntheses, stored back as memories and retrievable.
- Top-scoring memories that fit the window go into the prompt.
## Evidence
- Interview-based believability study with TrueSkill: full architecture mu=29.89, no-reflection ablation 26.88, and each further ablation lower; crowdworker authors scored below the full agent.
- Kruskal-Wallis H(4)=150.29, p<0.001 across conditions.
- Failure cases include agents embellishing their memories.
## Limits
- Short timescale; the human baseline was crowdworkers, not experts.
- Ablated components were assessed on one simulated town.
- Retrieval weights were all fixed at 1, not tuned; cost is high.
## We adopt
Retrieval ranking in tools/promote.py INDEX (DESIGN.md#retrieval): recency from last_verified, importance from helpful minus harmful counters, relevance from tags. Reflection feeds the learning loop (DESIGN.md#learning-loop).
## We reject
LLM-scored importance at write time and embedding search: we use observed counters and tags, which are deterministic and auditable. Reflections never auto-enter semantic memory.
