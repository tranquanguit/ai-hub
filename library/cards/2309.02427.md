## Claim
Language agents can be described uniformly by modular memories, a structured action space, and a repeated decision cycle.
## Mechanism
- Working memory holds the current cycle's state; long-term memory splits into episodic, semantic and procedural stores.
- Actions are external (grounding) or internal: retrieval, reasoning, learning.
- Each decision cycle plans with reasoning and retrieval, then picks one grounding or learning action.
- Learning is an explicit action: the agent chooses what to commit to long-term memory.
- Procedural memory covers both model weights and agent code; code edits are the riskier kind.
## Evidence
- Conceptual paper: no benchmark or experiment is reported.
- Retrospectively classifies many published agents (ReAct, Reflexion, Generative Agents and others) into the framework.
- Contrasts agents that fix a learning schedule with agents that decide when to learn.
## Limits
- No empirical test that the taxonomy predicts which design performs better.
- Leaves open the internal versus external memory boundary, and how autonomous learning should be controlled.
- Offers vocabulary, not an implementation.
## We adopt
Memory-tiers mapping in DESIGN.md#memory-tiers: working = context window plus LEDGER, episodic = memory/episodic, semantic = memory/semantic, procedural = skills plus scripts. The decision cycle becomes the fixed task-start, work, verify, close pipeline in DESIGN.md#fixed-pipelines. Learning is a deliberate, gated step, never a side effect.
## We reject
Letting the model rewrite its own agent code or semantic memory directly; the paper allows it, but we route writes through inbox and review. We also skip building a general production-rule decision engine; Claude Code's own loop is the cycle.
