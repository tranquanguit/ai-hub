## Claim
Having the model plan fact-checking questions and answer them separately from the draft reduces hallucinated facts.
## Mechanism
- Draft an initial response.
- Plan verification questions about the draft's claims.
- Answer each question independently, not conditioned on the draft, so errors are not copied.
- Write the final response consistent with the verified answers.
## Evidence
- Wikidata list questions, Llama 65B: precision 0.17 (few-shot) to 0.36 (two-step CoVe).
- Wiki-Category list task (Llama 65B, Table 1), precision: 0.12 (few-shot) to 0.22 (factored CoVe); Wikidata 0.17 to 0.32.
- Longform biographies, F1: 0.39 (few-shot) to 0.48 (factored CoVe).
- Authors state independent answering beats joint answering in the factored variants.
## Limits
- Reduces but does not remove hallucination.
- Checks only facts the model can recall; no external source.
- Extra model calls raise cost.
## We adopt
The task-close verification step lists explicit verification questions for each claim in a deliverable and answers them from sources, separately from the draft (.claude/skills/task-close).
## We reject
Answering verification questions from the model's memory alone; for us, answers must come from files, scripts or the owner.
