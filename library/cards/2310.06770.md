## Claim
Benchmarks built from real tasks and verified by running tests expose capability gaps that synthetic tasks hide.
## Mechanism
- Collect real GitHub issues paired with merged pull requests from 12 Python repositories.
- Keep only instances where at least one test flips from fail to pass after the reference patch.
- Score a model patch by running those tests plus the existing tests.
- Provide retrieval baselines (BM25) for supplying context.
## Evidence
- 2,294 task instances from 12 repositories.
- Best model, Claude 2 with BM25 retrieval, resolves 1.96% of issues.
- 40% of instances have at least two fail-to-pass tests; a median of 51 other tests guard against regressions.
## Limits
- Python only, popular open-source repositories.
- Tests can be incomplete, so passing is not proof of correctness.
- Retrieval quality limits scores independently of model ability.
## We adopt
Golden tasks come from real LunoBeau inputs, with execution-based checks where possible (DESIGN.md#evals, evals/run_cold_start.py).
## We reject
Scale: we keep a small curated set, not thousands of instances, and do not copy fail-to-pass test mining.
