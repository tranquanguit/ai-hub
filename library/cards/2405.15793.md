## Claim
An interface designed for the agent (few simple commands, concise output, guardrails) lifts task success more than a raw shell.
## Mechanism
- Small set of documented commands for viewing, searching and editing files.
- Search and view outputs are compact and capped.
- Edit command runs a linter and reverts edits that introduce syntax errors.
- Empty or unhelpful outputs return explicit messages.
## Evidence
- GPT-4 Turbo resolves 12.47% of the 2,294 SWE-bench tasks, versus 3.8% for the prior non-interactive best.
- On SWE-bench Lite, ACI beats the default Linux shell by 10.7 percentage points.
- Edit with linting scores 18.0 versus 15.0 for the edit action without it.
- 87.7% pass@1 on HumanEvalFix.
## Limits
- Designed and tuned for GPT-4 Turbo; portability was shown to one other model.
- Over half of trajectories (51.7%) contain a failed edit.
- Coding-specific; no claim about business tasks.
## We adopt
Repetitive operations become compact, documented scripts with short outputs and built-in validation, in tools/ (DESIGN.md#scripts-over-reasoning, RULES.md#r7).
## We reject
Building a full custom agent harness; Claude Code's own tools stay the base.
